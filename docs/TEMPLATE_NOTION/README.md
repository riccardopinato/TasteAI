## Regole stabili

Ogni nuovo template deve essere assegnato per coerenza del Product Bible; può essere respinto o condividere **solo il riferimento master** con altre app. Nessun file ZIP, asset, dati sensibili o ricette di terzi deve essere pubblicato. Aggiornare indice e `CATALOGO.json` insieme. Se non esiste valore originale per il prodotto, non trasformare il riferimento in SKU. Prezzo €3,99 soltanto idea commerciale.
